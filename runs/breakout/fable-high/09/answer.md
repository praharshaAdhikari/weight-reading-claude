**Design**

The policy predicts the column where the ball will be when it reaches row 8 and parks the paddle there, so the catch is a plain "paddle under the ball" hit with no-op as the final action. Nothing here was run or tested; the weights were checked by hand on a few traced trajectories.

- **Horizontal motion is predictable.** On an unfolded track of period 20 (columns 0..9, then 9..0, since a wall bounce pauses the ball one step), the ball advances exactly one cell per step. Only the time until it returns to row 8 is uncertain.
- **Lookahead L.** L is the number of steps until the ball is at row 8, assuming the earliest possible return:
  - descending or just bounced off a brick: `L = 8 - row`;
  - ascending at row 4 or below: `L = row + 1` (bounce off a row-3 brick).
  
  This is written as an additive table `fb(ball row) + ft(trail row)` with `fb = [8,7,6,5,4,3,1,-2,-6]` and `ft = [0,0,0,0,0,1,3,6,10]`. L never overestimates the true time, so later corrections are always delays the paddle can absorb.
- **Known approximation.** In the single frame right after a paddle hit (ball and trail both on row 8), the table gives L = 4 instead of 9. This can cost one wrong-direction step, but only in positions where there is plenty of slack.
- **Target.** With `s = bx + L` and `m = bx - L`, the target is `T = min(s, 19 - s)` when the ball moves right and `T = max(m, -1 - m)` when it moves left. The paddle moves toward T and does nothing when it is there.

**Hidden layer 1 (9 units used, gain 6, all saturated to about ±1)**

| Unit | Computes |
|---|---|
| 0 DIR | +1 if the ball's next horizontal move is right, from ball column minus trail column, with "away from the wall" when they are equal |
| 1 A | `s - p ≥ 1` |
| 2 B | `19 - s - p ≥ 1` |
| 3 C | `p - s ≥ 1` |
| 4 D | `p - (19 - s) ≥ 1` |
| 5 E | `m - p ≥ 1` |
| 6 F | `-1 - m - p ≥ 1` |
| 7 G | `p - m ≥ 1` |
| 8 H | `p + 1 + m ≥ 1` |

**Hidden layer 2 (4 units)**

- unit 0: go right, ball moving right = DIR ∧ A ∧ B
- unit 1: go left, ball moving right = DIR ∧ (C ∨ D)
- unit 2: go right, ball moving left = ¬DIR ∧ (E ∨ F)
- unit 3: go left, ball moving left = ¬DIR ∧ G ∧ H

**Output.** The right logit is +20 when either "go right" unit fires and −20 otherwise; left is the same for the "go left" units. No-op is 0 and up/down/fire are −40, so the sampled action is effectively deterministic.

With perfect actions the paddle always arrives in time; the only losses should come from unlucky sticky-action repeats, usually two in a row at a tight moment.
